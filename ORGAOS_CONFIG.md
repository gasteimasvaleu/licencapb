# O que preencher em Configurações → Órgãos

**Quem preenche:** o operador (você), uma vez por órgão. O Cowork só lê.
Estes textos são rascunhos feitos a partir de pesquisa na web, sem entrar nos
sites. Onde está **[confirmar]**, ajuste no primeiro protocolo real. Depois de
cada protocolo, corrija o passo a passo com o que de fato aconteceu.

Campos de cada órgão:
- **site_protocolo / site_consulta / forma_protocolo**: ver `ORGAOS.md`.
- **instrucoes**: avisos gerais (quem pode protocolar, o que conferir antes).
- **passo_a_passo**: um passo por linha.
- **exige**: o que precisa de uma pessoa. Marque só o que você confirmar no
  primeiro uso; na dúvida, marque (é melhor o Cowork parar à toa do que errar).

## SUDEMA

**forma_protocolo:** online

**instrucoes**
```
Protocolo pelo SIGMA (sigma.pb.gov.br). Conferir antes se o cadastro no SIGMA
está no nome da nossa empresa (procuradora) ou se precisa ser feito no nome do
cliente (empreendedor) [confirmar]. Verificar se o pedido exige publicação em
jornal/Diário Oficial e se o comprovante está entre os arquivos. Não pagar
taxas: gerar o boleto e passar para uma pessoa.
```

**passo_a_passo**
```
Entrar no SIGMA (sigma.pb.gov.br) com a conta da empresa
Abrir novo requerimento e escolher o tipo de licença do pedido
Preencher os dados do empreendimento e do requerente com o "Dados para copiar"
Anexar os arquivos do ZIP na ordem numerada
Revisar o resumo antes de enviar
Gerar o boleto da taxa (se houver) e passar para uma pessoa pagar
Enviar o requerimento e copiar o número do processo
```

**exige:** login com código no celular [confirmar] · pagamento de taxa

## CBMPB (Bombeiros)

**forma_protocolo:** online

**instrucoes**
```
O pedido de análise de projeto e de vistoria é feito no sistema eletrônico do
CBMPB pelo responsável técnico (engenheiro/arquiteto) [confirmar endereço do
sistema]. Conferir se o responsável técnico do pedido tem acesso ao sistema ou
se a conta é da nossa empresa. Conferir ART/RRT do projeto de incêndio antes.
```

**passo_a_passo**
```
Entrar no sistema eletrônico do CBMPB com a conta do responsável técnico
Escolher o tipo de solicitação: análise de projeto, vistoria ou reanálise
Preencher os dados da edificação com o "Dados para copiar"
Anexar projeto de incêndio, memorial e ART/RRT na ordem do ZIP
Gerar a taxa (se houver) e passar para uma pessoa pagar
Enviar e copiar o número do processo
```

**exige:** login com código no celular [confirmar] · pagamento de taxa

## AESA

**forma_protocolo:** online

**instrucoes**
```
Requerimento no site da AESA (Documentos → Requerimentos), com cadastro do
usuário. A resposta chega por e-mail: avisar a equipe quando chegar.
Para outorga de poço, conferir se há análise de água e o projeto técnico
assinado.
```

**passo_a_passo**
```
Entrar no site da AESA com a conta da empresa
Abrir Documentos → Requerimentos e escolher outorga ou licença de obra hídrica
Preencher o formulário com o "Dados para copiar" (usar a ficha de recursos hídricos)
Anexar os arquivos do ZIP na ordem numerada
Enviar e copiar o número de protocolo gerado
```

## IPHAEP

**forma_protocolo:** email

**instrucoes**
```
Protocolo pelo formulário online (iphaep.pb.gov.br/protocolo/requerimento) ou
por e-mail para protocolo@iphaep.pb.gov.br. Projeto precisa de RRT/ART do
arquiteto. A consulta de andamento é por e-mail/telefone [confirmar].
```

**passo_a_passo**
```
Abrir o formulário de requerimento do IPHAEP
Preencher endereço e dados cadastrais do imóvel (setor, quadra, lote) e o tipo de pedido
Anexar plantas, cortes, fachadas, memorial e RRT/ART do ZIP
Enviar e anotar o número ou guardar a confirmação recebida
Se o formulário não funcionar: enviar e-mail para protocolo@iphaep.pb.gov.br com os arquivos e o requerimento assinado
```

**exige:** nada previsto [confirmar]

## DER-PB

**forma_protocolo:** online

**instrucoes**
```
Pedido pela Plataforma Digital de Serviços (PDS), com link na página
der.pb.gov.br/faixa-de-dominio. Enviar só os documentos do tipo de cadastro
escolhido (pessoa física ou jurídica): documento faltando gera diligência.
```

**passo_a_passo**
```
Abrir der.pb.gov.br/faixa-de-dominio e clicar no link da PDS
Entrar com a conta da empresa
Abrir processo de uso da faixa de domínio / acesso
Escolher pessoa física ou jurídica conforme o requerente
Preencher os dados com o "Dados para copiar" e anexar os arquivos do ZIP
Enviar e copiar o número do processo
```

**exige:** login com código no celular [confirmar] · pagamento de taxa [confirmar]

## Receita Federal (CNO)

**forma_protocolo:** online

**instrucoes**
```
Inscrição no CNO pelo e-CAC (cav.receita.fazenda.gov.br) em até 30 dias do
início da obra. A obra fica no CPF/CNPJ do dono: precisa de procuração
eletrônica do cliente para a nossa empresa no e-CAC. Sem ela, quem faz é o
próprio cliente.
```

**passo_a_passo**
```
Entrar no e-CAC com o gov.br da empresa
Trocar o perfil para "Procurador" e informar o CPF/CNPJ do cliente
Abrir o serviço do Cadastro Nacional de Obras (CNO) e escolher inscrever obra
Preencher os dados da obra com o "Dados para copiar"
Confirmar e salvar o número do CNO e o comprovante em PDF
```

**exige:** login com código no celular · certificado digital [confirmar]

## SPU

**forma_protocolo:** online

**instrucoes**
```
Autorização de obras em imóvel da União pelo Portal SPU (a partir da página do
serviço no gov.br). Não se aplica a imóvel em ocupação ou aforamento: nesse caso
a autorização é com a prefeitura. Prazo de até 120 dias.
```

**passo_a_passo**
```
Abrir a página "Obter Autorização de Obras em Imóvel da União" no gov.br e clicar para iniciar
Preencher o requerimento com o "Dados para copiar"
Anexar memorial descritivo da poligonal e planta do terreno do ZIP
Marcar "Não sou robô" e passar para uma pessoa se aparecer captcha
Enviar e copiar o número do atendimento
```

**exige:** captcha · login com código no celular [confirmar]

```
Confirmar qual plataforma está valendo: a AWGPE é chamada de "antiga" pela

```
